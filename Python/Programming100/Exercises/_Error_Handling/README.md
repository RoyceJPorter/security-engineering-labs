# Exercise 10 - Error Handling

## Objective

Learn how to prevent application crashes and handle runtime errors gracefully.

## Concepts

- `try`
- `except`
- `else`
- `finally`
- Input validation
- Exception handling

## Cybersecurity Relevance

Security tools must handle unreliable input and operational failures without collapsing like a badly planned group project.

Common examples include:

- Missing files
- Invalid user input
- Network failures
- Permission errors
- Corrupted data
- Unexpected API responses

## Files

- `main.py`

## Engineering Reflection

### What I Learned

- Used exception handling to manage runtime errors.
- Prevented invalid input from terminating the application.
- Improved application reliability and user feedback.

### Potential Improvements

- Add logging for captured errors.
- Create custom exception types.
- Validate data before processing.
- Separate user errors from system errors.

### Real-World Applications

- Security automation
- File processing

- Network utilities
