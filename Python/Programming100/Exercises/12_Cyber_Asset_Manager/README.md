# Exercise 12 - Cyber Asset Manager

## Objective

Build a small command-line application that demonstrates the Python concepts learned throughout Programming100.

## Skills Demonstrated

- Variables
- Data Types
- User Input
- Conditional Logic
- Loops
- Functions
- Lists
- File Input / Output
- Error Handling
- Modules

## Project Overview

The Cyber Asset Manager is a simple command-line application that allows users to register, manage, and review cybersecurity assets.

The project demonstrates clean software organization, modular programming, and foundational engineering practices.

## Features

- Register assets
- Display assets
- Save assets to disk
- Load assets from disk
- Assign simple risk scores
- Modular architecture

## Files

- `main.py`
- `asset_manager.py`
- `file_manager.py`
- `risk.py`
