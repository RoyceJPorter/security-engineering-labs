# Exercise 11 - Modules

## Objective

Learn how to organize Python code across multiple files using modules.

## Concepts

- Importing modules
- Reusable functions
- Separation of concerns
- Code organization
- Maintainability

## Cybersecurity Relevance

Security tools often separate capabilities into reusable modules for:

- Asset processing
- Risk scoring
- Log parsing
- Detection logic
- Validation
- Reporting

Modular design makes applications easier to test, maintain, and expand.

## Files

- `main.py`
- `asset_utils.py`

## Engineering Reflection

### What I Learned

- Split application logic across multiple Python files.
- Imported reusable functions into the main program.
- Improved code organization and maintainability.

### Potential Improvements

- Add unit tests for each module.
- Create dedicated validation and reporting modules.
- Add type hints and structured logging.
- Package the project for reuse.

### Real-World Applications

- Security automation
- Detection engineering
- Incident-response tooling
- API integrations
- Asset management
