# Exercise 03 - Data Types

## Objective

Understand the primary built-in data types available in Python and when each should be used.

## Concept

Every value stored inside a Python program has a data type. Selecting the correct type improves readability, efficiency, and reliability.

## Learning Objectives

- Identify common data types
- Create variables using different types
- Understand mutable vs immutable concepts
- Display variable types
- Use the type() function

## Cybersecurity Relevance

Security tools continuously process different forms of data, including:

- Usernames (Strings)
- Port numbers (Integers)
- Confidence scores (Floats)
- Detection status (Booleans)
- Collections of IP addresses (Lists)
- Configuration settings (Dictionaries)

Understanding data types is essential when building automation, parsers, detection rules, and AI-assisted security tools.
