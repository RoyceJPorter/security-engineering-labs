# Exercise 01 - Hello World

## Objective

Create the first Python program while establishing professional project structure and version control practices.

## Concept

Every programming language begins with a simple program. While the code itself is trivial, this exercise establishes the workflow that will be used throughout this repository.

## Learning Objectives

- Create a Python script
- Execute a Python program
- Understand the `print()` function
- Practice project organization
- Use GitHub for version control

## Cybersecurity Relevance

Every cybersecurity tool begins with a single executable program. Whether developing automation scripts, detection utilities, or forensic tools, understanding the complete development workflow is more important than the complexity of the code itself.
