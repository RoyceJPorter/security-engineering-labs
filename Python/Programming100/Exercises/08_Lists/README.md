# Exercise 08 - Lists

## Objective

Learn how to store and process multiple objects using Python lists.

## Concept

Lists allow programs to store collections of related objects. When combined with dictionaries, they provide a flexible way to model structured data.

## Learning Objectives

- Create lists
- Store dictionaries inside lists
- Iterate through collections
- Display structured information
- Prepare data for automation

## Cybersecurity Relevance

Cybersecurity tools frequently process collections of assets, alerts, users, and indicators of compromise (IOCs).

Using lists and dictionaries together creates a scalable data structure that mirrors real-world security data.
