# Exercise 02 - Variables

## Objective

Practice creating, assigning, and using variables in Python.

## Concept

Variables store data that a program can use, update, and process during execution.

## Learning Objectives

- Create variables
- Assign values
- Use clear variable names
- Display variable values
- Update stored values
- Understand basic naming conventions

## Cybersecurity Relevance

Variables are used throughout cybersecurity tooling to store items such as:

- IP addresses
- File paths
- Usernames
- Hash values
- Port numbers
- Alert counts
- Risk scores

Clear variable names improve readability, reduce mistakes, and make security tools easier to review and maintain.
