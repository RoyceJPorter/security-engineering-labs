# Exercise 09 - File Input / Output

## Objective

Learn how to save and load data using text files.

## Concepts

- Opening files
- Reading files
- Writing files
- File paths
- Context managers (`with`)
- Persisting application data

## Engineering Objective

Applications should be able to preserve data after the program exits.

## Cybersecurity Relevance

Security tools constantly read and write data.

Examples include:

- Log files
- IOC lists
- Configuration files
- Reports
- Scan results

Understanding File I/O is a foundational software engineering skill.
