# Exercise 04 - User Input

## Objective

Learn how to collect information from a user during program execution.

## Concept

Python programs often require user input to make decisions, customize behavior, or process information. The `input()` function allows users to interact with a program.

## Learning Objectives

- Use the `input()` function
- Store user input in variables
- Display user-provided information
- Convert input into other data types
- Build interactive programs

## Cybersecurity Relevance

Most cybersecurity tools rely on user input, including:

- Target IP addresses
- Hostnames
- File names
- Domain names
- Usernames
- Port numbers
- Detection thresholds

Collecting and validating user input is one of the first steps toward building professional security utilities.
