# Exercise 05 - Conditional Logic

## Objective

Learn how to make decisions within a Python program using conditional statements.

## Concept

Conditional logic allows programs to execute different code paths depending on whether specific conditions evaluate to True or False.

## Learning Objectives

- Use if statements
- Use elif statements
- Use else statements
- Compare values
- Combine logical operators

## Cybersecurity Relevance

Security tools constantly make decisions based on collected information.

Examples include:

- Determining whether a port is privileged
- Classifying risk levels
- Identifying internal versus external IP addresses
- Detecting failed authentication attempts
- Evaluating security policy compliance

Understanding conditional logic is essential for building detection rules, automation scripts, and defensive security tools.
