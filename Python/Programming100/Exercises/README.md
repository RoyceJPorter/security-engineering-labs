# Programming 100 Exercises

This directory contains small Python exercises completed as part of my Programming 100 review and reinforcement.

## Purpose

These exercises reinforce the core concepts of Python programming while demonstrating clean coding practices and consistent version control.

Topics include:

- Variables
- Data Types
- User Input
- Conditional Logic
- Loops
- Functions
- Lists
- Dictionaries
- File Handling
- Error Handling
- Modules

Each exercise is intentionally small, focused, and documented to demonstrate steady engineering progression.
