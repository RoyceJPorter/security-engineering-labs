# Exercise 07 - Functions

## Objective

Learn how to organize Python programs into reusable functions.

## Concept

Functions allow developers to group related code into reusable blocks. This improves readability, reduces duplication, and makes programs easier to maintain.

## Learning Objectives

- Define functions
- Call functions
- Pass parameters
- Return values
- Improve code organization

## Cybersecurity Relevance

Functions are used throughout cybersecurity engineering to organize complex tasks into reusable components.

Examples include:

- Validating IP addresses
- Calculating risk scores
- Parsing log files
- Scanning hosts
- Reading configuration files
- Processing indicators of compromise (IOCs)

Breaking code into reusable functions improves maintainability and reduces errors.
