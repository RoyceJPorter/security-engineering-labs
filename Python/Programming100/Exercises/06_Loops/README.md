# Exercise 06 - Loops

## Objective

Learn how to repeatedly execute code using Python loops.

## Concept

Loops allow programs to perform repetitive tasks efficiently without duplicating code.

## Learning Objectives

- Use `for` loops
- Use `while` loops
- Iterate over collections
- Control repetition
- Improve program efficiency

## Cybersecurity Relevance

Loops are essential in cybersecurity engineering and automation.

Examples include:

- Scanning multiple hosts
- Processing log files
- Enumerating users
- Reading alerts
- Reviewing network connections
- Checking indicators of compromise (IOCs)

Understanding loops is fundamental to building scalable security tools.
